КМАН — Прикладна механіка та машинобудування. 22 тематичні модулі (12+10), усі мають коротку теорію, інтерактивну параметричну навчальну модель, гіпотезу, конструктор дослідження, перевірку знань, мініпроєкт і друк PDF. Увага: моделі спрощені навчальні, не інженерні розрахунки. Розпакуйте ZIP у корінь GitHub Pages. Для автопублікації ZIP потрібен окремий GitHub Actions workflow.


## Оновлення: предметні лабораторії
У 11 технічно доречних модулях додано спеціалізовані симулятори: балка, передачі, коливання, матеріали, композит, різання, допуски, вимірювання, креслення, опора. Решта модулів залишаються без штучних фізичних симуляторів. В усіх 22 модулях додано тематичні ілюстрації. Зображення — кадровані фрагменти згенерованих інженерних концепт-візуалізацій, не технічні креслення. Розрахунки навчальні, припущення описано в інтерфейсі. Для PDF використовується друк браузера.

## Різноманітні інтерактиви
У 18 змістово відповідних модулях додано шість типів завдань: пошук несправностей, помилки на кресленнях, дослідження з даними, винахідницькі задачі, аналіз даних, патентний детектив. Рішення зберігаються локально, а текст обґрунтування додається до друкованого PDF. Навчальні дані й ескізи умовні.
