# КМАН — укрупнені модулі курсу

Джерело: навчальна програма «Прикладна механіка та машинобудування», М. Блощицин, 2026, Google Drive.

- Перший рік: 12 модулів, 324 години.
- Другий рік: 10 модулів, 324 години.
- Всього: 22 модулі, 648 годин.
- Пілотний інтерактивний модуль: module-1-01.html.
- Інші сторінки — структура і перелік об’єднаних тем, а не готові уроки.
- pilot-lesson-01.html — попередня пробна сторінка (збережена для порівняння, може використовувати попередні ресурси).
- PDF через браузер: Друк → Зберегти як PDF.
- Розгортання: завантажити в корінь GitHub репозиторію, Settings → Pages → Deploy from a branch → main / root.
- Автоматичне оновлення через GitHub API не підключено.
